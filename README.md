## Deploy on GitHub Pages
1. Create a repository (for example `nidhi-portfolio`).
2. Put `index.html`, `README.md`, and the `assets/` folder in the repository root.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.

The site uses Tailwind via CDN and Google Fonts, so it does not require a build step.
